# Фінансування для PHANTOM OS — огляд програм (стан на 2026-07-05)

Профіль: соло-фаундер, ФОП (Україна), hardware+software AI-продукт, продажі через LemonSqueezy.
Потреби: невеликий хостинг, хмарні AI-кредити, живі гроші до стабільних продажів.

Перевірено пошуком станом на сьогодні — там, де джерела суперечать одне одному або дані застаріли,
позначено **«потребує перевірки вручну»**.

## Деталі по кожній програмі

### Microsoft for Startups Founders Hub
- **Статус**: активна, без дедлайнів, приймає цілий рік.
- **Що дає**: базовий рівень (без інвесторів) — $1,000 Azure-кредитів одразу, до $5,000 після верифікації бізнесу. Повний Founders Hub (з traction) — до $150,000 Azure за 4 роки, плюс OpenAI API credits, GitHub Copilot, технічна підтримка.
- **Вимоги**: продукт на основі софту, який належить компанії; компанія молодша 7 років. Не потрібні інвестиції, акселератор чи revenue.
- **Заявка**: https://www.microsoft.com/en-us/startups — онлайн-форма, рішення за кілька днів.
- **Шанси**: **висока**. Це найлегший вхід — ФОП з власним AI-продуктом підходить ідеально під "Basic Path".

### AWS Activate Founders
- **Статус**: активна.
- **Що дає**: $1,000 AWS-кредитів (пакет Founders).
- **Вимоги**: self-funded/bootstrapped, до 10 років компанії, <10 співробітників, <$1M фандингу/виручки, немає VC/акселератора, робочий сайт компанії, платний AWS tier (не тільки free tier).
- **Заявка**: https://aws.amazon.com/startups/credits/ — рішення за 7-10 робочих днів.
- **Шанси**: **висока**, але сума менша ніж Azure/GCP базовий рівень.

### Google for Startups Cloud Program (Start tier)
- **Статус**: активна.
- **Що дає**: $2,000 Cloud-кредитів для bootstrapped стартапів (без equity-фандингу), плюс окремий AI-трек для продуктів на основі AI.
- **Вимоги**: рання стадія, без інституційного фінансування для рівня Start.
- **Заявка**: https://cloud.google.com/startup/apply — відповідь за 3-5 робочих днів.
- **Шанси**: **висока**.

### NVIDIA Inception
- **Статус**: активна, без дедлайнів і зборів, приймають цілий рік.
- **Що дає**: до $100,000 AWS-кредитів + до $100,000 DGX Cloud (H100), знижки на GPU, безкоштовний технічний тренінг, необмежене прототипування через NVIDIA NIM API (build.nvidia.com).
- **Вимоги**: хоча б 1 розробник, робочий сайт, офіційна реєстрація (< 10 років компанії); revenue НЕ обов'язковий. Явно сказано: "solo researcher" теж підходить. Виключені: консалтингові/аутсорс-фірми, крипто-компанії, cloud-провайдери, реселери, публічні компанії.
- **Заявка**: https://www.nvidia.com/en-us/startups/ — потрібна коротка pitch-презентація (місія/продукт/команда/traction), відповідь за 2-4 тижні.
- **Шанси**: **висока**. Ідеально пасує під AI-продукт на власному залізі.

### Cloudflare for Startups
- **Статус**: активна.
- **Що дає**: Tier 3 (bootstrapped, <$1M залучено) = $10,000 кредитів на рік (Workers, R2, D1, Workers AI до $50k у складі загального пакету тощо). Домени/enterprise-фічі не покриваються.
- **Вимоги**: софтверний продукт з активним сайтом, засновано < 5 років тому, LinkedIn-профіль.
- **Заявка**: https://www.cloudflare.com/startups/
- **Шанси**: **середня-висока** — легко пройти поріг входу, але потрібен готовий сайт продукту.

### GitHub Accelerator
- **Статус**: **невідомо для 2026** — офіційна сторінка accelerator.github.com не підтверджує новий цикл; останній підтверджений цикл — 2024 (дедлайн 05.03.2024). 2026-й тематично орієнтований на "AI advancements in the open", але точних дат заявок не знайдено. **Потребує перевірки вручну** на accelerator.github.com.
- **Що дає**: $40,000 + менторство + Azure-кредити + GitHub Copilot, 10-тижнева когорта (потрібно 40 год/тиждень).
- **Вимоги**: **обов'язково open-source проєкт з чіткою ліцензією і активною спільною**, contributor/maintainer 18+.
- **Шанси**: **низька** для PHANTOM OS у поточному вигляді (закритий комерційний продукт). Могло б підійти лише якби виокремити й відкрити один з компонентів (наприклад, tool_registry чи shared types) як самостійний OSS-проєкт — але це окрема стратегічна дія, не швидкий крок.

### Грант «Власна справа» (єРобота / Дія.Бізнес)
- **Статус**: активна програма, з 01.01.2026 діють нові (описані нижче) умови, з 01.09.2026 планується ще одне розширення (до 500k база, до 2.5 млн на масштабування — деталі оновлення **потребують перевірки вручну** ближче до вересня).
- **Суми (з 01.01.2026)**:
  - 100,000 грн — без вимоги нового робочого місця (для фізособи, яка щойно відкриває ФОП);
  - 200,000 грн — за 1 нове робоче місце;
  - 300-350,000 грн — за 2 робочих місця (діючий ФОП/мале підприємство);
  - до 500,000 грн — прифронтові регіони, 2 робочих місця;
  - до 150,000 грн — молодь до 25 років, без обов'язкового найму.
- **Вимоги**: подача через Дія (BankID/e-підпис), бізнес-план за шаблоном Мінекономіки з детальним кошторисом, банківська перевірка репутації, співбесіда з центром зайнятості. **Обов'язкова умова**: вести діяльність не менше 3 років і (для сум від 200k) створити нові робочі місця — для соло-фаундера це реальний бар'єр, бо потрібно офіційно найняти хоча б одну людину.
- **IT-прийнятність**: КВЕД 62.01 (комп'ютерне програмування), 62.02, 62.09 у явному переліку заборонених не значаться (заборонені лише зброя/алкоголь/тютюн/фінустанови/діяльність у рф-рб) — тобто софт-розробка ФОП **має право** подаватись, але одне джерело (csr.community) прямо не вдалося відкрити (403) — варто перепровірити реальний % відмов і практичні підводні камені вручну на csr.community/hranty-na-vlasnu-spravu.
- **Заявка**: https://diia.gov.ua/services/grant-na-vlasnu-spravu
- **Шанси**: **середня**. Гроші реальні й ФОП підходить формально, але вимога найму працівника — це або витрата (зарплата+ЄСВ), або треба знайти конструкцію (наприклад, часткова зайнятість) — вимагає окремого рішення, чи виправдано брати грант під таку умову.

### Ukrainian Startup Fund (USF) — Startup EDGE
- **Статус**: активний фонд, але конкретний цикл Startup EDGE мав дедлайн **21.01.2026** — уже минув. USF регулярно відкриває нові цикли (Startup school, акселераційні програми) — **потребує перевірки вручну** на https://usf.com.ua/en/ і https://portal.usf.com.ua/ щодо наступного відкритого набору.
- **Що дає**: гранти до €40,000 для команд з MVP/першою валідацією ринку (загальний бюджет циклу €1,000,000, конкурсний відбір).
- **Вимоги**: зазвичай реєстрація в Україні, стартап-профіль, MVP чи ранній traction.
- **Шанси**: **середня** — сильний профіль (готовий продукт, hardware+AI), але треба зловити момент відкриття наступного набору.

### Seeds of Bravery (UASEEDs, EIC-фінансований консорціум)
- **Статус**: активна, €20M від Європейської комісії, кілька програм-потоків, нові когорти виходять протягом 2026 (остання підтверджена — 38 стартапів отримали €1.25M).
- **Що дає**: гранти €10,000–€50,000 на потік, сукупно не більше €60,000 з усього консорціуму.
- **Вимоги**: компанія зареєстрована в Україні АБО релокована в ЄС/Horizon-асоційовану країну після 24.02.2022; проєкт має мати "європейський вимір" (потенціал виходу на ринок ЄС). **Потребує перевірки вручну**: чи достатньо ФОП, чи консорціум вимагає юридичну особу (типово гранти ЄС видаються юрособі, а не фізичній особі-підприємцю — це відрізняється від Дія-грантів).
- **Заявка**: https://seedsofbravery.eu/ — короткий admissibility-check, потім повна заявка через систему USF.
- **Шанси**: **середня** — продукт (AI-компаньйон на власному залізі) добре лягає в наратив "deep tech з України", але юридична форма отримання коштів треба уточнити до подачі.

### Google for Startups Ukraine Support Fund
- **Статус**: **закрита**. Другий фонд (2024-2025) завершив активне фінансування; наразі триває тільки супровід уже профінансованих компаній. Нового набору не анонсовано.
- **Шанси**: немає сенсу подаватись зараз.

### EU4Business / ЄБРР — консультаційні гранти
- **Статус**: активна (заявки приймаються постійно, без дедлайну).
- **Що дає**: компенсація 50-85% вартості консалтингового проєкту (маркетингова стратегія, ISO, автоматизація, енергоаудит), типова сума гранту — до €10,000.
- **Вимоги**: бізнес має працювати понад 2 роки з позитивною динамікою. **Потребує перевірки вручну**: скільки років фактично зареєстрований ваш ФОП — якщо менше 2 років, це не підходить зараз.
- **Заявка**: https://eu4business.org.ua/
- **Шанси**: **низька-середня**, залежно від стажу ФОП; і це кошти на консалтинг, не на хмару/розробку напряму.

### EU4Business (грант на обладнання через Дія, до €10,000)
- **Статус**: знайдено підтвердження лише для циклу 2023 (дедлайн 25.08.2023), вимагав юрособу з 11-49 співробітниками. Схоже, що це вже закрита програма або чекає нового циклу під новою назвою — **потребує перевірки вручну**, чи є активний новий раунд у 2026.
- **Шанси**: **немає** для соло-ФОП навіть якщо відкриється новий раунд (поріг 11-49 співробітників).

### Brave1
- **Статус**: активна, приймає заявки цілий рік без дедлайну.
- **Що дає**: 500 тис – 8 млн грн залежно від рівня готовності рішення (TRL), максимум 30 млн грн/рік на розробника; окремий грантовий конкурс саме на AI-рішення для поля бою.
- **Вимоги**: діяльність спрямована на оборонні технології/підвищення обороноздатності; фізичні особи-громадяни можуть подавати.
- **Шанси**: **низька для PHANTOM OS у теперішньому вигляді** — це персональний AI-компаньйон, не defense tech. Могло б стати актуальним лише якщо є конкретний dual-use сценарій (наприклад, версія для розвідки/спостереження/аналізу сенсорних даних на фронті) — це вимагало б окремого продуктового пітчу, не просто подачі поточного продукту.

### EIC Accelerator
- **Статус**: активна, дедлайни повних заявок 2026: 7 січня, 4 березня, 6 травня, 8 липня, 2 вересня, 4 листопада.
- **Що дає**: грант-онлі (для маштабування) АБО blended finance — грант + €1-10M інвестицій (пряма участь у капіталі/квазі-капітал через EIC Fund).
- **Вимоги**: Україна — асоційована країна Horizon Europe, тож українські компанії формально мають право подаватись; допускаються "natural persons or legal entities willing to set up an SME". Бюджет Accelerator Open 2026 — €414M.
- **Застереження**: інвестиційна частина (blended finance) практично завжди вимагає юридичну особу з капітальною структурою (акції/частки) — **потребує перевірки вручну**, чи можна податись як ФОП на grant-only варіант без конвертації в ТОВ.
- **Шанси**: **середня** — сильний продукт і чіткий deep-tech наратив можуть пройти, але процес довгий (кілька місяців, багатоступеневий відбір), і майже напевно доведеться зареєструвати юридичну особу до отримання коштів.

### Kickstarter
- **Статус**: Україна **не входить** у список із 25 країн, де дозволено запускати проєкти (Австралія, Австрія, Бельгія, Канада, Данія, Франція, Німеччина, Греція, Гонконг, Ірландія, Італія, Японія, Люксембург, Мексика, Нідерланди, Нова Зеландія, Норвегія, Польща, Сінгапур, Словенія, Іспанія, Швеція, Швейцарія, Велика Британія, США).
- **Обхідний шлях (легальний)**: зареєструвати проєкт через партнера/співзасновника чи юридичну особу в одній із дозволених країн (наприклад, Польща чи Литва — там простіше і дешевше зареєструвати компанію нерезиденту). Це окремий і не тривіальний крок.
- **Шанси**: немає напряму з ФОП в Україні.

### Indiegogo
- **Статус**: доступний. Немає формального процесу схвалення, достатньо банківського рахунку — фактично прийнятий і для ФОП.
- **Вимоги**: банківський рахунок для виведення коштів; податки за обраною системою оподаткування ФОП.
- **Шанси**: **середня** — платформа технічно доступна, але успіх кампанії залежить від готової аудиторії/маркетингу, а не від бар'єрів входу. Український приклад: кампанія на адаптери для Android Auto зібрала $650k від 7000 бекерів — доводить, що це працює для укр. hardware-продуктів.

### Українські краудфандингові платформи (На-Старт, BigIdea, StartEra, Спільнокошт)
- **Статус**: активні у 2026 (декілька платформ закрились у 2021-2024, залишилась приблизно п'ятірка робочих).
- **Що дає**: різні суми, комісія ~8% від зібраного (На-Старт), орієнтація радше на соціальні/культурні/громадські проєкти ніж на tech hardware.
- **Шанси**: **середня** — менший потенційний чек ніж Kickstarter/Indiegogo через локальну аудиторію, але простіший вхід і підтримка українською.

### USAID гранти для МСБ
- **Статус**: **закриті/призупинені** — USAID згорнув операції в Україні (наслідок федеральних змін у США); альтернативні донори (ЄС, міжнародні фонди) заповнюють частину прогалини.
- **Шанси**: не актуально, не витрачати час на подачу.

## Топ-3 дії цього місяця

1. **Подати одразу на 3 хмарні програми з найвищим співвідношенням зусилля/результат: Microsoft for Startups Founders Hub + AWS Activate Founders + Google for Startups Cloud Program (Start).**
   Усі три не вимагають ТОВ, не вимагають інвестицій, приймають ФОП/соло-фаундера, рішення за дні. Це закриває "невеликий хостинг + хмарні AI-кредити" майже одразу.
   - https://www.microsoft.com/en-us/startups
   - https://aws.amazon.com/startups/credits/
   - https://cloud.google.com/startup/apply

2. **Подати заявку в NVIDIA Inception.**
   Найбільший потенційний обсяг кредитів (до $100k AWS + $100k DGX Cloud) серед хмарних програм, приймають соло-дослідників і хардверні AI-продукти без обов'язкового revenue. Потрібна коротка pitch-презентація — підготувати сьогодні-завтра.
   - https://www.nvidia.com/en-us/startups/

3. **Оцінити грант «Власна справа» на Дія (100k-350k грн живими грошима) — але спершу зважити вимогу найму працівника.**
   Це єдина з перевірених програм, яка дає **живі гроші, а не кредити**, і ФОП тут прийнятний формально. Перед подачею: (а) уточнити на порталі Дія точний актуальний перелік заборонених КВЕД станом на липень 2026, (б) прорахувати, чи виправдано найняти 1 людину під суму 200-350k грн (зарплата + ЄСВ на рік може з'їсти більшу частину гранту), (в) підготувати бізнес-план за шаблоном Мінекономіки.
   - https://diia.gov.ua/services/grant-na-vlasnu-spravu

**Паралельно, без дедлайну цього місяця**: подати заявку в Cloudflare for Startups (Tier 3, $10k) — займає 15 хвилин, і слідкувати за відкриттям нового циклу USF (Startup EDGE наступний раунд) та Seeds of Bravery.

## Головні сюрпризи

- **Google for Startups Ukraine Support Fund — уже закритий** (фінансування завершено 2024-2025, зараз лише супровід профінансованих). Не варто витрачати час на заявку.
- **Kickstarter недоступний для України взагалі** (не входить у 25 дозволених країн) — треба обхідний шлях через юрособу в іншій країні, або одразу фокусуватись на Indiegogo/передзамовленнях через власний сайт.
- **GitHub Accelerator вимагає open-source ліцензію та публічну спільноту** — для закритого комерційного продукту типу PHANTOM OS це не підходить без окремої стратегії (виділити й відкрити один модуль).
- **USAID гранти для МСБ фактично зникли** з 2025 року — раніше це був стандартний пункт у будь-якому списку "гранти для укр. бізнесу", зараз актуальні джерела прямо кажуть "closed/suspended".
- **Грант «Власна справа» вимагає найм працівника** для сум від 200,000 грн — для соло-фаундера це не безкоштовні гроші, а зобов'язання з реальною вартістю (зарплата + ЄСВ), що варто прорахувати перед подачею.
- **EU4Business consulting-грант вимагає 2+ роки діяльності бізнесу** — і окремий грант на обладнання через Дія (€10k) виявився для юросіб з 11-49 співробітниками (цикл 2023) — жоден з двох напрямів EU4Business не пасує напряму соло-ФОП без стажу.
