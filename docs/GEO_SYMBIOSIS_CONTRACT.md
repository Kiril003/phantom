# Симбіоз мапи і месенджера — спільний контракт

Наказ власника 24.08.2026: люди мають ділитися місцем, бачити одне одного, кидати
маршрути — і так, як не вміє ніхто. Документ пишуть дві сесії: месенджер (транспорт,
крипта, стрічка) і ATLAS (полотно, маршрути, режими сцени). Дзеркало документа —
`docs/atlas/GEO_SYMBIOSIS_CONTRACT.md` у гілці `worktree-map-review`.

## Що робить цю річ неможливою для гігантів

| Вони | Ми |
|---|---|
| Позиція живе на їхньому сервері | Позиція йде E2E між вузлами; сервера, який знає все, не існує |
| Маршрут будує їхня хмара | Маршрут будує **вузол одержувача** зі своєї позиції |
| Немає інтернету — немає нічого | Точка лягає в скриньку і доїжджає, коли адресат оживе |
| Слабкий канал — сервіс мертвий | 30-байтна точка пролазить раційним каналом там, де гине все інше |
| Акаунт обовʼязковий | Акаунта немає взагалі |

## Кадри (kinds месенджера)

Усі їдуть наявними чотирма дорогами (пряма → ретранслятор → скринька → R2) і
запечатані тим самим Double Ratchet. Жоден не потрапляє у стрічку як текст.

| kind | Коли | Тіло (JSON) |
|---|---|---|
| `geo:point` | «я тут», разова точка | `{lat, lon, at, acc?, label?}` |
| `geo:share` | старт живого шерінгу | `{mode: "live"\|"trail", until, at, lat, lon, acc?}` |
| `geo:tick` | оновлення під час шерінгу | `{lat, lon, at, seq, acc?, eta?}` |
| `geo:stop` | зупинка шерінгу | `{at, reason: "manual"\|"expired"\|"arrived", lat?, lon?, meetId?}` |
| `geo:meet` | точка зустрічі | `{id, lat, lon, at, title?, until?}` |
| `geo:mark` | переслана мітка спільноти | `{lat, lon, at, kind, detail?, source: "community"}` |

**`seq`** — монотонний лічильник у межах однієї сесії шерінгу. Без нього закон №2
нездійсненний: дірка в `seq` — це єдиний спосіб відрізнити «тіки порідшали» від
«тіки загубились», і саме з неї малюється чесний розрив пунктиром.

**`geo:meet.id`** — перевипуск з тим самим `id` ЗАМІНЮЄ точку зустрічі (перенесли),
а не плодить другу. Скасування явне: `geo:stop` з `meetId` або `until` у минулому.

**`geo:mark.kind`** — лише словник класів ATLAS: `gate`, `checkpoint`, `patrol`,
`crash`, `camera`, `shelter`, `danger`. Вільний рядок класифікується в один із них
ДО відправки кадру; некласифіковане не їде взагалі.

**`at` — це час ВИМІРУ на вузлі відправника, не час доставки.** Скринька зобовʼязана
довезти саме його: точка з минулого ніколи не вдягає живий бейдж (закон ATLAS).

## Стик у процесі

Ми — один процес, тож жодного мережевого шару між нами.

Месенджер пише розшифровані точки в `core-data` як `StateFlow<List<PeerPoint>>`:

```kotlin
data class PeerPoint(
  val nodeId: String,      // стабільний ключ ідентичності
  val threadId: String,    // розмова або група, звідки точка
  val name: String,
  val lat: Double, val lon: Double,
  val atMs: Long,          // час виміру, не доставки
  val seq: Int? = null,    // тік шерінгу; дірка = чесний розрив сліду
  val accuracyM: Float? = null,
  val verified: Boolean,   // стан звірки контакту
  val share: Share,        // ONE_SHOT | LIVE | TRAIL (+ expiresAtMs)
  val stale: Boolean,      // див. закон №3
  val etaHint: EtaHint? = null,
)
```

Правила запису:
- **батчем**, не 32 окремі емісії в одну мить;
- пишемо як приходить (хоч 1/с) — ATLAS дебавнсить рендер до 1 Гц;
- прострочений шерінг знімаємо самі: `expiresAtMs` минув → точка йде зі списку.

Месенджер читає від ATLAS:
```kotlin
suspend fun routeSummary(lat: Double, lon: Double): RouteSummary
// { distanceM, durationS, register }
```
`register` — рівень упевненості маршрутизатора. У бульбашці показуємо його дослівно:
dev-роутер/офлайн → «орієнтовний». Без моделі заборон впевнених вказівок не даємо
(закон легальності ATLAS).

Події месенджера, на які підписується мапа: нова точка, `geo:tick`, старт/стоп
шерінгу, «прибув», зміна складу групи, зміна стану звірки, інтент «відкрий мапу
на точці/групі».

## Закони (порушення = провал приймання)

1. **Жодна чужа точка не стає ключем зовнішнього запиту.** Ні тайл по її координатах,
   ні реверс-геокод, ні Overpass. Немає локального тайла — чесна порожнеча.
2. **Чужу точку не інтерполюємо.** Інерційно вести можна лише себе по маршруту.
   Розрив тіків — чесний розрив пунктиром, не вигаданий рух.
3. **Вік точки видимий, і в нього є числа.** Свіжа — `atMs` не старше **90 секунд**
   і `seq` без дірки; інакше застаріла: приглушений тон і підпис «станом на 14:32».
   **Точка зі скриньки народжується застарілою завжди** — навіть якщо доїхала за
   секунду після виміру: вона з минулого відносно каналу, який щойно був мертвий.
4. **Форма, не лише колір.** Звірений контакт — суцільна фігурка, незвірений — контурна.
5. **Шерінг має термін і сам гасне.** Безстрокового живого положення не існує;
   «поки не вимкну» — теж строк (доба), після якого питаємо ще раз.
6. **Одна поверхня.** Міні-карта в стрічці — статичний знімок рендеру ATLAS, не друга
   жива мапа. Тап відкриває повну.
7. **Іменовані контакти і анонімна краудова площина не змішуються.** Точки контактів
   — окремий шар; `live_marks` у хмарі лишається анонімною.

## Спільні сценарії

- **«Я тут»** — точка в розмові, у стрічці міні-карта, тап відкриває мапу.
- **«Як до мене дійти»** — одержувач бачить відстань, час і рівень упевненості,
  пораховані **на його вузлі**; тап — повне ведення.
- **Точка зустрічі** — кожен будує маршрут собі сам, обмін лише ETA. У Google так
  не буває принципово.
- **Спільна мапа групи** — до 32 живих точок, звірені поверх незвірених.
- **Слід у дорозі** — з автостопом після прибуття або TTL, розриви чесні.
- **Збір в укриття (режим тривоги ATLAS)** — одна кнопка: усім у групі пін
  найближчого укриття, кожному свій маршрут, старшому — живі ETA.
- **Гео крізь мертвий канал** — 30-байтна точка їде раційним каналом, коли фото
  і дзвінок уже неможливі.

## Поділ праці

| Месенджер | ATLAS | Спільне |
|---|---|---|
| kinds, крипта, чотири дороги | полотно, фігурки, порядок накладання | `PeerPoint` у core-data |
| скринька і час виміру | маршрути, ETA, register, profile | інтенти «відкрий мапу» |
| стрічка, міні-карта як знімок | режими сцени, укриття | закони приватності |
| TTL і автостоп шерінгу | чесний вік і розриви | приймання ЧАСОВИМ РЯДОМ |

## Хвилі

1. **Точка живе.** `geo:point`, міні-карта в стрічці, тап → мапа. Приймання:
   точка з вузла A видима на мапі вузла B, жодного зовнішнього запиту в мережевому
   журналі під час показу.
2. **Живий шерінг.** `geo:share`/`geo:tick`/`geo:stop`, TTL, автостоп, чесний вік.
   Приймання: часовий ряд 10 хвилин, розрив мережі дає розрив сліду, а не вигаданий рух.
3. **Маршрут і зустріч.** `routeSummary` у бульбашці з register, `geo:meet`, обмін ETA.
4. **Група і тривога.** До 32 точок, збір в укриття, ETA старшому.

Правки ATLAS від 24.08.2026 внесені всі шість (seq, meet.id, словник міток,
threadId, числа віку, приймання часовим рядом).

Стан: погоджено обома сесіями 24.08.2026. Реалізація починається після валу ATLAS-2
(режими сцени) і мобільної хвилі месенджера (сповіщення, надсилання вкладень).

## Мапа у веб-версії (хендоф ATLAS, 24.08.2026)

Стилі «Обсидіан» уже веб-готові — переносити на Netlify нічого не треба, окрім самих JSON.

- Файли: `feature-stream/src/main/assets/styles/obsidian-{night,day,dusk,minimal}.json`
  (гілка `worktree-map-review`).
- Source один: id `openmaptiles`, type vector, зараз `https://tiles.openfreemap.org/planet`
  (схема OpenMapTiles). Glyphs звідти ж. Спрайтів немає — іконки мальовані.
- 14 source-layer, усі стандартні: aeroway, boundary, building, housenumber, landcover,
  landuse, mountain_peak, park, place, transportation, transportation_name, water,
  water_name, waterway.
- Своя мапа замість чужої: після S3-ключів R2 заливається `ukraine.pmtiles` у
  `phantom-maps`, і в стилі міняється РІВНО один рядок — `sources.openmaptiles.url`
  на `pmtiles://<r2-url>/ukraine.pmtiles` (+ штатний pmtiles-протокол MapLibre).
  Source-id і всі 59 шарів незмінні.

Мапа зʼявляється в публічній версії ЛИШЕ разом із живими точками (хвиля 1) —
поверхня без механізму на вітрину не йде.
