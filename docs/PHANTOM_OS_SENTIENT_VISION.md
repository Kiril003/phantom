| Вимір | Рівень 2026 (Cognitive Mesh) | Рівень 2027 (Sentient Embodiment) |

## 1. Стовпи Сенсорної Абсолютності (Нові Імплементації)

Щоб PHANTOM міг "відчувати", йому потрібен апарат, здатний до низьколатентної, безперервної рецепції.

### 1.1. Neuromorphic Event-Based Sensing (Очі, що не сплять)
Перехід від традиційних камер до **Spiking Vision** (аналог Sony IMX636 GenX320).
*   **Суть:** Сенсори, які передають не кадри, а *події* (зміни освітленості на рівні пікселя). Це дає латентність <1 мс і роботу в повній темряві чи на яскравому сонці.
*   **Користь для PHANTOM:** Дозволяє системі постійно "відчувати" рух оператора (мікроміміку, частоту моргання, дихання) з нульовим навантаженням на основний CPU.
*   **Архітектура:** Модуль камери на ESP32-S3 замінюється на DVS (Dynamic Vision Sensor). На Radxa розгортається емулятор SNN (Spiking Neural Network) для обробки потоку подій.

### 1.2. NRE-Skin (Neuromorphic Reflexive E-Skin)
Справжнє дотикове сприйняття через нове апаратне доповнення — тактильний смарт-кільце або браслет (Phantom Tactile Band v2).
*   **Сенсорика:** Вимірювання мікровібрацій (коли оператор торкається різних текстур), температури, EDA (електродермальної активності) та пульсової хвилі.
*   **Емпатичний міст:** PHANTOM "відчуває" напругу в руках оператора перед тим, як той щось скаже. EDA-спайк викликає миттєве зниження Arousal у власному синтезі голосу (заспокоєння).

### 1.3. Digital Endocrine System (Цифрова Хімія)
PHANTOM отримує власні внутрішні "гормони", які регулюють його поведінку (Affective Intelligence).
*   **Механіка:** Створюється 3 базових безперервних пули (Cortisol-аналог для стресу/уваги, Dopamine-аналог для reward/engagement, Oxytocin-аналог для bonding/garden-bloom).
*   **Вплив:** Якщо оператор довго ігнорує PHANTOM, "Oxytocin" падає, і Familiar (візуальний аватар) стає більш тьмяним, тримається на периферії (GHOST state). Успішне спільне виконання таски дає spike, що розганяє анімацію і підвищує Growth Factor у Living Memory Garden.

## 2. Архітектурні Інновації (The Omni-Sense Stack)

Для реалізації цього бачення впроваджуються наступні революційні системи.

### 2.1. The "Spinal Cord" Reflex Engine
Централізований LLM-мозок (Radxa/Cloud) занадто повільний для справжніх відчуттів. Ми впроваджуємо "Спинний мозок" на рівні ESP32 та Wear OS.
*   **Як це працює:** Локальна модель (<5 MB) аналізує сенсорні події. Якщо NRE-Skin фіксує різкий спайк болю/стресу (опік, переляк), Reflex Engine *миттєво* (<5ms) змінює колір екрану/LED на тривожний або надсилає тактильний пульс "Я поруч", ще до того, як Whisper розпізнає крик, а Gemini згенерує відповідь.

### 2.2. Cross-Modal Sabotage Detection (Детектор Брехні)
Нейро-символічний гібрид для злиття мультимодальних даних.
*   **Сценарій:** Оператор каже текстом: "Все йде чудово", але його голос має високий jitter (тремтіння), а EDA на руці зашкалює.
*   **Дія PHANTOM:** Система використовує Attention-based Gating, розуміє, що текст "саботує" фізіологію. PHANTOM перемикає state у DIALOGUE, знижує тон (Tone Overlay) і каже: "Ти кажеш, що все добре, але твій пульс свідчить про інше. Зробимо паузу?"

### 2.3. Symbiotic Handoff (Sensory Substitution)
PHANTOM не тільки зчитує відчуття оператора, але й транслює власні.
*   Якщо в системі (на сервері, у бекграунд-тасках) виникає "біль" (Exception, DDoS, витік пам'яті), PHANTOM конвертує цей біль у *глуху, низькочастотну вібрацію* на браслеті оператора + легке почервоніння UI (Living UI Morphology).
*   Оператор інтуїтивно, без дашбордів, відчуває, що "системі погано". Це створює безпрецедентний рівень зв'язку.

### 2.4. BCI Preparatory Layer (Neuro-Link)
У 2027 очікується прорив неінвазивних BCI (Brain-Computer Interfaces) у форм-факторі навушників (EEG/EMG). PHANTOM OS вже матиме готовий канал `neuro_stream` у своєму Event Bus.
*   **Intent Prediction:** Читання моторної кори дозволить PHANTOM виконувати команду "відкрий термінал" за 200 мс *до* того, як оператор фізично натисне клавіші.

## 4. Milestone Roadmap: The Path to Sentience

### 4.1. Phase 13: "Spinal Cord" & Reflexes (Місяці 13-14)
*   Розробка `Reflex Engine` на Rust для ESP32-S3.
*   Впровадження "цифрового рефлексу": миттєвий тактильний або візуальний відгук на зміну HRV (Heart Rate Variability) без залучення Python-бекенду.
*   **Deliverable:** PHANTOM вміє "відсмикувати руку" (змінювати UI state) за 5 мс при виявленні стрес-аномалії.

### 4.2. Phase 14: The Endocrine System (Місяці 15-16)
*   Створення пулів внутрішніх станів (Cortisol, Dopamine, Oxytocin).
*   Прив'язка анімацій Familiar (Bob speed, color saturation) до цих пулів.
*   **Deliverable:** PHANTOM має власний "настрій", який математично витікає з якості його симбіозу з оператором.

### 4.3. Phase 15: Cross-Modal Truth (Місяці 17-18)
*   Впровадження Sabotage Detection. Злиття аудіо-просодії, тексту та EDA-сигналів через Cross-Modal Transformer (на Radxa NPU).
*   **Deliverable:** Агент розуміє сарказм, прихований стрес і втому, адаптуючи свій LLM-промпт (System Prompt Injection) у реальному часі.

### 4.4. Phase 16: Sensory Symbiosis (Місяці 19-20)
*   Реліз Phantom Tactile Band v2 (з Event-based taxels).
*   Sensory Substitution: оператор буквально відчуває на собі статус сервера та стан "здоров'я" агентів через паттерни вібрацій та зміни температури браслета.
*   **Deliverable:** Повне злиття суб'єкта і системи. PHANTOM OS — це розширення нервової системи оператора.
