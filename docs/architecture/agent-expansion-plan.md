# Розширення Підсистеми Агента (Agent Expansion Plan)

## 1. Концепція "Паралельного Чату" (Side-Channel)
**Проблема:** Зараз, якщо агент виконує довгу задачу (напр., розгортання інфраструктури або аналіз коду), оператор не може запитати його про щось інше без переривання (Intervention/Council).
**Рішення:**
- Створення `SideChannel` на бекенді (окремий маршрут `/api/v1/agent/chat`). Цей канал використовує ту саму пам'ять (ChromaDB), але працює як stateless (або окремий легкий) LLM-виклик, який не блокує `loop.py`.
- На фронтенді: `ParallelChatDrawer.tsx` (згорнута панель або плаваюче вікно, створене в Google Stitch). Оператор може запитати: "Скільки ще залишилося?" або "Знайди мені файл X", поки агент працює.

## 2. Інформативність та Структура Даних (Теки)
**Проблема:** Звіти та історія сесій виглядають як плоский список.
**Рішення:**
- **UI:** Використовуючи Google Stitch, спроектувати нове вікно "Agent Vault" або "Intel Hub". 
- **Розділи:**
  - 📁 **Звіти (Reports):** Фінальні `AgentReportScreen`, згенеровані після успішних тасків.
  - 📁 **Чати (Chats):** Історія `SideChannel` розмов.
  - 📁 **Архіви (Archives):** Старі сесії, лонги, дампи внутрішнього монологу.
- Дані будуть зберігатися в існуючій базі (SQLite) з новими тегами категорій.

## 3. Внутрішні та Зовнішні Коміти (Rollback System)
**Проблема:** Агент може змінити код так, що все зламається.
**Рішення (Система Time-Machine):**
- **Внутрішні (State Checkpoints):** Збереження стану самого агента (його пам'ять, поточні саб-голи). Вже частково є, але треба винести в UI.
- **Зовнішні (Git Rollback):**
  - Створення нового інструменту `agent/actions/git_checkpoint.py`.
  - Перед виконанням `high_risk_action` (напр., масовий рефакторинг), агент автоматично робить `git add . && git commit -m "phantom_auto_checkpoint_task_{id}"`.
  - Якщо Quality Gate фейлиться або юзер каже "Відміняй", агент автоматично робить `git reset --hard HEAD~1`.
  - **UI:** У вікні агента буде кнопка "⏳ Rollback (Git)", яка показує останні авто-коміти.

## 4. Масштабованість (Smarter & Better)
