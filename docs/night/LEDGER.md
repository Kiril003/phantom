## Прийняті рішення та Політика продукту
1. **Мова інтерфейсу:** 100% Українська. Всі кнопки, підказки, статуси систем, ролі та оверлеї (AgentRoster, AgentVault) локалізовано без англіцизмів.
2. **Системні іконки:** Використання чистого SVG (Lucide-react) замість сирих emoji в UI компонентах (AgentRoster).
3. **Нуль конфігу (Zero Config):** Зрозумілі підказки для порожніх станів (наприклад, у Сховищі додано опис для відсутності знайдених задач/звітів).
