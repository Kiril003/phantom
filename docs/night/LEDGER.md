## Прийняті рішення та Політика продукту
1. **Мова інтерфейсу:** 100% Українська. Всі кнопки, підказки, статуси систем і порожні стани локалізовано без сирих англіцизмів чи невідформатованих enum.
2. **Нуль конфігу (Zero Config):** Зрозумілі підказки для порожніх станів (наприклад, для відсутності фонових процесів, постійних доручень або Ради агентів пояснено алгоритм їхньої появи).
3. **Гнучкі верстки:** Використання `min-w-*`, `flex-wrap` та адаптивних контейнерів для запобігання обрізанню довших українських фраз.
4. **Контроль заліза (15 ГБ RAM, RTX 5060):** Послідовний запуск важких збірок і тестів, перевірка вільної пам'яті (`free -m`) перед розгортанням.
