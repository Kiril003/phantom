# PHANTOM OS — Журнал Продукту (LEDGER)

## Поточний стан
- **Версія / Напрямок:** Phantom OS Desktop Shell & Multi-Tenant Hybrid Platform (Python FastAPI + React Vite TS + Tauri Desktop).
- **Останні зміни:**
  - Реалізовано базову підтримку SaaS ізоляції орендарів (Tenant Isolation) у бекенді: `src/backend/core/tenant.py`, `src/backend/api/routes_tenant.py`, `src/backend/security/rate_limiter.py`.
  - Додано юніт-тести SaaS: `test_tenant_isolation.py` та `test_rate_limiter.py` (6 з 6 успішних тестів).
  - Створено плашку орендаря у фронтенді `TenantBadge.tsx` та інтегровано в `OperatorLayout.tsx`.

## Пастки та Обмеження Ресурсів
- **Залізо:** 15 ГБ RAM, RTX 5060, Linux.
- **Правило 1:** Жодних паралельних важких складань чи одночасного прогону повних тест-сюїт.
- **Правило 2:** Вільна пам'ять перевіряється перед збіркою (`free -m`). Якщо <2 ГБ — очищаємо процеси та чекаємо.
- **Правило 3:** Українська мова інтерфейсу — без англіцизмів у відкритому UI, без сирих `enum.name`, без вигадування даних.
- **Правило 4:** Нуль конфігу — не вимагати від користувача ключів чи IP в лоб. Дозволи — за контекстом.

2. **Перевірка збірки фронтенду:** Провести чисту збірку React (`npm run build`) та Vitest перевірку UI компонентів.
