## Rationale
Обраний підхід базується на систематичному дослідженні, емпіричному тестуванні та порівняльному аналізі. Це дозволяє прийняти обґрунтоване технічне рішення, що відповідає специфічним апаратним обмеженням (ARM64, ОЗП) та вимогам до продуктивності (латентність < 150 мс), мінімізуючи ризики при інтеграції довготривалої пам'яті. Такий підхід забезпечує надійну основу для подальшого розвитку архітектури PHANTOM.
