# Architectural Decision: Аналіз та вибір векторної бази даних (ChromaDB vs Qdrant vs pgvector) для Radxa Dragon Q6A з подальш

- **Task ID:** 86749147-3a31-4222-8dcc-82d0c407a85c
- **Date:** unknown

## Rationale
Обраний підхід базується на принципі 'знизу-вгору' для систем з обмеженими ресурсами, де спочатку перевіряється сумісність апаратного забезпечення та ефективність ключових компонентів (модель ембеддінгів), а потім здійснюється вибір та інтеграція системи зберігання (векторна БД). Це мінімізує ризики, пов'язані з розгортанням ресурсоємних рішень на слабкій платформі, що було причиною попередніх невдач.
