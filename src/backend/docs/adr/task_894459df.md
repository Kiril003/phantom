# Architectural Decision: Розробити архітектурний проєкт системи довготривалої пам'яті, провести порівняльний аналіз легковаго

- **Date:** unknown

## Rationale
Підхід пріоритезує легковагові, локальні рішення, оптимізовані для архітектури ARM64 та обмежених ресурсів. Це передбачає вибір векторних баз даних та моделей ембеддінгів, відомих своєю ефективністю та легкістю розгортання в таких середовищах, уникаючи важких контейнеризованих рішень до перевірки сумісності ресурсів. Модульний дизайн відокремлює генерацію ембеддінгів від зберігання, дозволяючи незалежне тестування та майбутні оновлення.
