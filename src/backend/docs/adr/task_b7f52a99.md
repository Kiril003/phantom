# Architectural Decision: скільки файлів у папці завантажень?

- **Task ID:** b7f52a99-18f5-42e9-ad43-4ba82a8e043d
- **Date:** unknown

## Rationale
Використання стандартної команди Bash (`ls -1 ~/Downloads | wc -l`) є найефективнішим та найнадійнішим способом підрахунку файлів у каталозі. Це прямий підхід, що не потребує складних інструментів, додаткових залежностей чи доступу до файлової системи за межами стандартних команд.

## Required Capabilities
- bash.run
