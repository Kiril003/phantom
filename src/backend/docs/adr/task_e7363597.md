# Architectural Decision: Розробити порівняльний аналіз векторних баз даних (ChromaDB, Qdrant, pgvector) для локального викори

- **Task ID:** e7363597-6d40-44c8-a5f1-241e0e1e79fa
- **Date:** unknown

## Rationale
Обраний підхід пріоритезує ефективність локальних ресурсів та сумісність з ARM64 шляхом спочатку створення легковажного конвеєра генерації локальних ембеддінгів, а потім систематичної оцінки продуктивності та споживання ресурсів кожної векторної бази даних на цільовому обладнанні. Ця модульна оцінка дозволяє прийняти обґрунтоване рішення на основі емпіричних даних перед інтеграцією у фінальний прототип, зменшуючи ризики, пов'язані з ресурсоємними рішеннями.

## Required Capabilities
- Python 3.x
- pip
- sentence-transformers
- torch (CPU)
- psycopg2/psycopg
- PostgreSQL
- pgvector extension
- ChromaDB client/server (standalone/in-memory)
- Qdrant client/server (standalone/in-memory)
